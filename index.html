Strategy Architecture

How the Strategy Works

Rather than relying on a single lagging oscillator, trades are triggered only when multiple independent technical factors agree. Orders are executed strictly on bar close to guarantee that backtested metrics match real forward execution.

Pillar 1

200 EMA Macro Trend Filter

Trades are only taken in the direction of the dominant market regime. Long entries require price to close above the 200 Exponential Moving Average; short entries require price below it.

ta.ema(close, 200) Prevents counter-trend whipsaws
Pillar 2

Supertrend Volatility Breakout

Detects momentum shifts and trailing trend reversals using an Average True Range (ATR) band. Signals occur on the precise candle where price crosses and flips the Supertrend line.

ta.supertrend(3.0, 10) Entry trigger with dynamic trailing
Pillar 3

RSI Momentum Confirmation

Validates relative strength before committing capital. Long orders require RSI(14) ≥ 50 to confirm bullish velocity; short orders require RSI ≤ 50, preventing entries into exhausted moves.

ta.rsi(close, 14) >= 50 Filters out weak momentum signals
Pillar 4

Volume Spike Validation

Confirms that breakout candles are backed by real trading volume above the 20-period volume simple moving average. Helps weed out low-liquidity slippage during sideways consolidation.

volume > ta.sma(volume, 20) Filters low-liquidity false breakouts

Long Entry Criteria

  • Price is trading above 200 EMA
  • Supertrend flips Bullish (crossover)
  • 14-period RSI is ≥ 50
  • Candle volume is above 20-SMA volume
  • Inside allowed session hours (09:15 - 15:15 for NSE)

Short Entry Criteria

  • Price is trading below 200 EMA
  • Supertrend flips Bearish (crossunder)
  • 14-period RSI is ≤ 50
  • Candle volume is above 20-SMA volume
  • Inside allowed session hours (09:15 - 15:15 for NSE)

Risk Management & Exits

  • Stop-Loss: Dynamic 1.5 × ATR or fixed percentage
  • Take-Profit: Calculated using target Risk:Reward (default 1:2)
  • Trailing SL: Ratchets forward candle-by-candle with ATR
  • Intraday Square-off: Auto-closes all NSE positions at 15:15 IST

Strategy Script Code

Copy the complete script directly into TradingView's Pine Editor. No dependencies or external libraries required.

Indian_Crypto_Pro_Strategy.pine TradingView Pine Script v5 
//@version=5
strategy("Multi-Asset Pro Strategy [NSE / BSE / Crypto]", overlay=true, initial_capital=100000, default_qty_type=strategy.percent_of_equity, default_qty_value=10, commission_type=strategy.commission.percent, commission_value=0.05, process_orders_on_close=true)

// ==========================================
// 1. INPUT PARAMETERS & USER CONFIGURATION
// ==========================================

// --- Asset Mode & Session Control ---
string asset_mode   = input.string("NSE / BSE Stock Market", "Asset Class Preset", options=["NSE / BSE Stock Market", "Crypto 24/7", "Custom"], group="Market Configuration", tooltip="Select market type for pre-tuned filters.")
string trade_type   = input.string("Intraday", "Trading Style", options=["Intraday", "Swing Trading"], group="Market Configuration")
string session_time = input.session("0915-1515:23456", "NSE Trading Session (IST)", group="Market Configuration", tooltip="Active trading hours for Indian stock market.")
bool   sqoff_enable = input.bool(true, "Intraday Auto Square-Off at 15:15 IST", group="Market Configuration", tooltip="Automatically exit open positions before market close.")

// --- Trend & Signal Engines ---
bool   use_ema_filter = input.bool(true, "Enable 200 EMA Trend Filter", group="Signal Engine Settings")
int    ema_len        = input.int(200, "Base EMA Length", minval=10, group="Signal Engine Settings")

// Supertrend Inputs
int    st_atr_period  = input.int(10, "Supertrend ATR Period", minval=1, group="Signal Engine Settings")
float  st_factor      = input.float(3.0, "Supertrend Factor", minval=0.5, step=0.1, group="Signal Engine Settings")

// RSI Oscillator Inputs
bool   use_rsi_filter = input.bool(true, "Enable RSI Confirmation", group="Signal Engine Settings")
int    rsi_len        = input.int(14, "RSI Length", group="Signal Engine Settings")
int    rsi_buy_thresh = input.int(50, "RSI Buy Threshold (>)", group="Signal Engine Settings")
int    rsi_sell_thresh= input.int(50, "RSI Sell Threshold (<)", group="Signal Engine Settings")

// Volume Spike Confirmation
bool   use_vol_filter = input.bool(true, "Require Above-Average Volume", group="Signal Engine Settings")
int    vol_ma_len     = input.int(20, "Volume Moving Avg Length", group="Signal Engine Settings")

// --- Risk Management & Targets ---
string sl_tp_mode     = input.string("ATR Dynamic", "Stop Loss / Take Profit Mode", options=["ATR Dynamic", "Percentage Based", "Fixed Points"], group="Risk Management")
float  atr_sl_mult    = input.float(1.5, "ATR Stop Loss Multiplier", minval=0.5, step=0.1, group="Risk Management")
float  rr_ratio       = input.float(2.0, "Risk Reward Ratio (TP = SL * RR)", minval=0.5, step=0.1, group="Risk Management")
bool   use_trail_sl   = input.bool(true, "Enable Trailing Stop Loss", group="Risk Management")

// Percentage Mode Defaults
float  pct_sl         = input.float(1.0, "Fixed SL %", minval=0.1, step=0.1, group="Risk Management")
float  pct_tp         = input.float(2.0, "Fixed TP %", minval=0.1, step=0.1, group="Risk Management")

// --- Dashboard & Alert UI ---
bool   show_dashboard = input.bool(true, "Show Performance Dashboard Table", group="UI & Display Settings")
string dash_pos       = input.string("Top Right", "Dashboard Position", options=["Top Right", "Bottom Right", "Top Left", "Bottom Left"], group="UI & Display Settings")

// ==========================================
// 2. INDICATOR COMPUTATIONS
// ==========================================

// Base Trend Filter
float base_ema = ta.ema(close, ema_len)
bool  is_bull_ema = close > base_ema
bool  is_bear_ema = close < base_ema

// Supertrend Engine
[st_value, st_direction] = ta.supertrend(st_factor, st_atr_period)
bool is_st_bull = st_direction < 0
bool is_st_bear = st_direction > 0

// RSI Engine
float rsi_val = ta.rsi(close, rsi_len)
bool  is_rsi_bull = rsi_val >= rsi_buy_thresh
bool  is_rsi_bear = rsi_val <= rsi_sell_thresh

// Volume Engine
float vol_ma = ta.sma(volume, vol_ma_len)
bool  is_vol_ok = use_vol_filter ? (volume > vol_ma) : true

// Session & Time Engine
bool in_session = asset_mode == "Crypto 24/7" ? true : not na(time(timeframe.period, session_time))
bool is_square_off_time = (asset_mode == "NSE / BSE Stock Market" and trade_type == "Intraday" and sqoff_enable) ? (hour == 15 and minute >= 15) : false

// ATR Calculation for SL / TP
float atr_val = ta.atr(14)

// ==========================================
// 3. ENTRY & EXIT CONDITIONS
// ==========================================

bool buy_condition  = (not use_ema_filter or is_bull_ema) and is_st_bull and ta.crossover(close, st_value) and (not use_rsi_filter or is_rsi_bull) and is_vol_ok and in_session
bool sell_condition = (not use_ema_filter or is_bear_ema) and is_st_bear and ta.crossunder(close, st_value) and (not use_rsi_filter or is_rsi_bear) and is_vol_ok and in_session

// Position Tracking Variables
var float long_sl = 0.0
var float long_tp = 0.0
var float short_sl = 0.0
var float short_tp = 0.0

// Trigger Buy Signal
if (buy_condition and strategy.position_size == 0)
    if (sl_tp_mode == "ATR Dynamic")
        long_sl := close - (atr_val * atr_sl_mult)
        long_tp := close + ((close - long_sl) * rr_ratio)
    else if (sl_tp_mode == "Percentage Based")
        long_sl := close * (1 - pct_sl / 100)
        long_tp := close * (1 + pct_tp / 100)

    strategy.entry("BUY", strategy.long, alert_message='{"action": "BUY", "symbol": "' + syminfo.ticker + '", "price": ' + str.tostring(close) + '}')

// Trigger Sell / Short Signal
if (sell_condition and strategy.position_size == 0)
    if (sl_tp_mode == "ATR Dynamic")
        short_sl := close + (atr_val * atr_sl_mult)
        short_tp := close - ((short_sl - close) * rr_ratio)
    else if (sl_tp_mode == "Percentage Based")
        short_sl := close * (1 + pct_sl / 100)
        short_tp := close * (1 - pct_tp / 100)

    strategy.entry("SELL", strategy.short, alert_message='{"action": "SELL", "symbol": "' + syminfo.ticker + '", "price": ' + str.tostring(close) + '}')

// Dynamic Trailing Stop Updates
if (strategy.position_size > 0 and use_trail_sl)
    float new_sl = close - (atr_val * atr_sl_mult)
    if (new_sl > long_sl)
        long_sl := new_sl

if (strategy.position_size < 0 and use_trail_sl)
    float new_sl = close + (atr_val * atr_sl_mult)
    if (new_sl < short_sl)
        short_sl := new_sl

// Execute Exits (SL / TP)
if (strategy.position_size > 0)
    strategy.exit("Exit BUY", "BUY", stop=long_sl, limit=long_tp, alert_message='{"action": "EXIT_BUY", "symbol": "' + syminfo.ticker + '", "price": ' + str.tostring(close) + '}')

if (strategy.position_size < 0)
    strategy.exit("Exit SELL", "SELL", stop=short_sl, limit=short_tp, alert_message='{"action": "EXIT_SELL", "symbol": "' + syminfo.ticker + '", "price": ' + str.tostring(close) + '}')

// Intraday Session Square-off
if (is_square_off_time and strategy.position_size != 0)
    strategy.close_all(comment="Intraday Auto Square-Off 15:15 IST", alert_message='{"action": "SQUARE_OFF", "symbol": "' + syminfo.ticker + '"}')

// ==========================================
// 4. CHART PLOTS & VISUALS
// ==========================================

plot(use_ema_filter ? base_ema : na, "200 EMA Macro Trend", color=color.new(#2563eb, 0), linewidth=2)
plot(st_value, "Supertrend Band", color=st_direction < 0 ? color.new(#16a34a, 0) : color.new(#dc2626, 0), linewidth=2)

plotshape(buy_condition and strategy.position_size == 0, "Buy Signal", shape.triangleup, location.belowbar, color.new(#16a34a, 0), size=size.small, text="BUY")
plotshape(sell_condition and strategy.position_size == 0, "Sell Signal", shape.triangledown, location.abovebar, color.new(#dc2626, 0), size=size.small, text="SELL")

// Plot Live Targets and Stops
plot(strategy.position_size > 0 ? long_sl : na, "Long Stop Loss", color=color.new(#dc2626, 20), style=plot.style_linebr, linewidth=2)
plot(strategy.position_size > 0 ? long_tp : na, "Long Take Profit", color=color.new(#16a34a, 20), style=plot.style_linebr, linewidth=2)
plot(strategy.position_size < 0 ? short_sl : na, "Short Stop Loss", color=color.new(#dc2626, 20), style=plot.style_linebr, linewidth=2)
plot(strategy.position_size < 0 ? short_tp : na, "Short Take Profit", color=color.new(#16a34a, 20), style=plot.style_linebr, linewidth=2)

// ==========================================
// 5. ON-SCREEN HUD PERFORMANCE TABLE
// ==========================================

var table hud = table.new(position.top_right, 2, 6, bgcolor=color.new(#1e293b, 10), border_color=color.new(#475569, 0), border_width=1)

if (show_dashboard and barstate.islast)
    table.cell(hud, 0, 0, "Multi-Asset Strategy", bgcolor=color.new(#1e3a8a, 20), text_color=color.white, text_size=size.small)
    table.cell(hud, 1, 0, asset_mode, bgcolor=color.new(#1e3a8a, 20), text_color=color.white, text_size=size.small)

    table.cell(hud, 0, 1, "Macro Trend (200 EMA)", text_color=color.gray, text_size=size.small)
    table.cell(hud, 1, 1, is_bull_ema ? "BULLISH" : "BEARISH", text_color=is_bull_ema ? color.green : color.red, text_size=size.small)

    table.cell(hud, 0, 2, "Supertrend Regime", text_color=color.gray, text_size=size.small)
    table.cell(hud, 1, 2, is_st_bull ? "BULLISH" : "BEARISH", text_color=is_st_bull ? color.green : color.red, text_size=size.small)

    table.cell(hud, 0, 3, "RSI (14)", text_color=color.gray, text_size=size.small)
    table.cell(hud, 1, 3, str.tostring(rsi_val, "#.##"), text_color=color.white, text_size=size.small)

    table.cell(hud, 0, 4, "Win Rate", text_color=color.gray, text_size=size.small)
    float win_rate = strategy.closedtrades > 0 ? (strategy.wintrades / strategy.closedtrades * 100) : 0.0
    table.cell(hud, 1, 4, str.tostring(win_rate, "#.##") + "%", text_color=color.yellow, text_size=size.small)

    table.cell(hud, 0, 5, "Net P&L", text_color=color.gray, text_size=size.small)
    table.cell(hud, 1, 5, str.tostring(strategy.netprofit, "#.##"), text_color=strategy.netprofit >= 0 ? color.green : color.red, text_size=size.small)

Frequently Asked Questions & Technical Notes

Does this script repaint historical bars?

No. The strategy has process_orders_on_close = true enabled, ensuring orders only execute once a candle has officially closed and its values are immutable.

Which timeframe is best for Indian intraday trading?

The 5-minute and 15-minute timeframes generally yield the cleanest Supertrend signals while filtering out market-open noise on high-beta NSE stocks.

Can I run this without webhooks?

Yes. Webhooks are completely optional. You can use it as a manual visual indicator on your charts to assist discretionary trade entries and trailing exits.

How does the 15:15 IST Auto Square-off work?

When running under NSE / BSE Stock Market mode with Intraday selected, the script triggers an automatic exit order at 15:15 IST, protecting you from broker penalty fees.
